## Evidence And Scope

The pages use 37 original photo files: 30 new assets and seven reused, byte-identical existing assets. Sources include Joe's Drive, all three Reverb inventory states and the three Deluxe photos Joe identified in Downloads. Original bytes and dimensions are retained. Every condition example keeps its disclosed refinish, contour, ferrule, tuner or pickup-conversion history. Modern instruments appear only in authentication comparisons.

The 80 price rows use the authenticated 2026 book and frozen per-row adjustments. Raw source values and random assignments remain under ignored `work/model-guides-4/`. Public JSON holds adjusted figures only. `value-chart-check.json` records source page and arithmetic results without exposing raw book figures.

The price-book 1972 Deluxe rows and 1968 sunburst Thinline row are omitted because Fender's production histories disagree with those year labels. Duplicate 1971 three-bolt natural Thinline categories are consolidated. No price is extrapolated beyond the last available 1978 Thinline row. Generic Telecaster color categories require individual assignment; no unsupported color mapping is invented.

One original Bass VI photo set was found. Its four switches, mute and smooth pickup surrounds are described as visible evidence, with the history of that combination unresolved. The second vintage Deluxe's exact year is left unspecified. The Esquire's visible 4-57 heel is decoded as April 1957, separately from assembly.

Existing pages gain contextual link paragraphs only. The original source is preserved after removing those insertions. Protected J-200, Rickenbacker and existing GuideActions pages are checked against a pristine main build with the same production environment. A duplicated Esquire image was reused from its existing path to avoid changing old rendered asset URLs.

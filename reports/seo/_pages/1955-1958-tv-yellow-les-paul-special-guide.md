### 8. DB fact check

Cross-checked the page's factual claims against VG-0001..VG-0112. Findings:

**Looks consistent with the DB:**
- Kluson Deluxe single vertical stamp / brass-post aging — consistent with **VG-0019** (Kluson Deluxe single vertical stamp ~1950s) and **VG-0002** (Kluson stamp dates the tuner, not the guitar — worth weaving in as a caveat).
- CRL/Centralab pot codes, "134" prefix, year+week reading — matches **VG-0047** (134 = CentraLab), **VG-0099/0101/0102** (pot code = maker + YEAR then WEEK). The page's worked example "134812 = 12th week of 1958" is consistent with VG-0102's structure.
- Nitrocellulose lacquer description — matches **VG-0104** (nitro = thin solvent-based DuPont finish).
- Refinish "cuts value in half" / humbucker-rout "30-50%" — directionally consistent with **VG-0074/0107** (refin ≈ -40% avg) and **VG-0112** (originality is the #1 value driver). The page's "half" for a refin is steeper than VG-0074's ~40% average but within the cited range; not a contradiction, but consider softening to "roughly 40 to 50%" to match the DB's evidence base.
- All-original / "dead-original" framing — matches **VG-0106** (all-original definition) and **VG-0112**.

**⚠️ Potential CONFLICT to verify:**
- The page (timeline + FAQ) states the single-cut → **double-cut transition happened in late 1958**. **VG-0021** says "Gibson redesigned the Les Paul into the thinner, double-pointed-cutaway 'SG' shape for **1961**." These are about different models (VG-0021 = Les Paul Standard→SG in 1961; the page = Les Paul *Special* going double-cut in 1958). They are NOT actually contradictory — the Special and Junior went double-cut in 1958-59, the Standard went SG-shape in 1961 — but a reader/auditor could read them as conflicting. **Recommend: keep the page claim (it's correct for the Special) and add a DB fact distinguishing the two transitions** (see below) so the KB doesn't appear to contradict itself.

**Facts on this page that are MISSING from the DB and worth adding:**
1. **Les Paul Special single-cut → double-cut transition = late 1958** (distinct from the 1961 LP-Standard→SG change in VG-0021). Source: page body + widely documented. Add as a new VG fact scoped [Gibson], explicitly noting it differs from VG-0021's model/date.
2. **Gibson 1950s ink-stamp serial: first digit = last digit of year (5/6/7/8 → 1955/56/57/58), stamped in black ink ON TOP of the lacquer.** The DB has the modern YDDDYRRR system (VG-0035) and FON year-letters (VG-0034) but no entry for the 1952-1960 solid-body ink-stamp first-digit-of-year rule that this page documents. Solid, verifiable, and reused across all the Gibson model pages — good KB addition. Source: page "Dating by Serial Number" + dataset-schema.md references a Gibson "ink-stamp solid-body (1952-1960)" table on the SN page.
3. **FON letter prefixes W=1955, X=1956, Y=1957, U/V=1958.** The DB's VG-0034 covers FON trailing-letter A-H for 1935-1942 only; this page documents a different FON prefix scheme for 1955-1958. Verify against the live Gibson SN guide before adding (these FON-prefix schemes are contested in the literature) — flag as needs-source-confirmation, not a clean add.
4. **P-90 single-coil DC resistance ~7.5-8.5k ohms (Special spec table).** The DB has no P-90 output fact. Minor, but a clean spec-table value worth capturing.

No outright WRONG claims found. The two items to action: (a) soften "cuts value in half" toward the VG-0074 ~40-50% range, and (b) add the missing 1955-1958 serial/FON/transition facts so the KB is complete and doesn't appear to clash with VG-0021.

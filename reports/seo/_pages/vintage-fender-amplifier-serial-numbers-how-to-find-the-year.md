### 3. FAQ gaps

The page has **no FAQ section and no FAQPage JSON-LD** at all — a real gap for an Archetype-B reference page (every other serial guide on the site carries FAQ schema, per CLAUDE.md). The questions below mirror real "fender amp serial" search intent (gsc) and would earn FAQPage rich-result eligibility. Add as a collapsible accordion before §tc-10, with FAQPage JSON-LD.

- **Q: Can I date a vintage Fender amp by its serial number?** A: No — Fender amp serial numbers weren't sequential and Fender kept no serial-to-date records, so the serial alone won't give you a year. Use the tube-chart date code, then transformer/speaker codes and era features. *(Needs DB fact — cite **VG-0052**: "Fender amplifiers generally cannot be dated by serial number for vintage units because Fender kept no serial records.")*
- **Q: Where is the date code on a Fender amp?** A: It's the ink-stamped two-letter code on the paper tube chart glued inside the chassis (usually the left inner side). First letter = year (A=1951 … T=1970), second letter = month (A=January … L=December). *(Self-contained from §tc-2 + decoder; no DB fact needed.)*
- **Q: What if my Fender amp's tube chart is missing?** A: Date it by era appearance (Tweed 1948-1959, Blonde/Brownface 1959-1963, Blackface 1963-1967, Silverface 1967-1980) combined with the speaker or transformer codes, which give the last digit of the year. *(Self-contained from §tc-3–§tc-9.)*
- **Q: How do I read a Fender speaker code?** A: It's a 6-digit, numbers-only code: a 3-digit manufacturer (EIA) code, then 3 digits where the first gives the last digit of the year and the rest the week. Cross-reference the era to resolve the decade (a "5" is 1955, 1965, or 1975). *(Self-contained from §tc-9. NOTE for the writer: the page calls this a "3 digit manufacturer code"; the EIA source-date system in **VG-0047 / VG-0101** is a real cross-reference if you want to name CTS=137 / CentraLab=134 / Stackpole=304, but keep the FAQ answer simple.)*

### 8. DB fact check

Cross-checked the page's factual claims against VG-0001…VG-0112.

**Claims that CHECK OUT (consistent with DB):**
- §tc-1: "Fender amp serial numbers are not useful for finding their year… weren't always sequential." ✅ Matches **VG-0052** ("Fender amplifiers generally cannot be dated by serial number for vintage units because Fender kept no serial records"). Solid; this is the page's thesis and the DB backs it.
- §tc-2 tube-chart table: A=1951 through T=1970, first letter = year, second = month. ✅ Consistent with **VG-0052** (tube chart is the method). The letter-year mapping is the standard accepted Fender tube-chart code; no contradicting VG fact.
- §tc-9: speaker/transformer codes = 3-digit manufacturer (EIA) code + year/week digits, giving only the last digit of the year. ✅ Aligns with **VG-0047** (EIA prefixes 134/137/304), **VG-0048 / VG-0100** (EIA codes give only the EARLIEST possible build date), and **VG-0102** (digits after the maker code = year then week). The page's "first number… indicates the last number in the year of manufacture" is correct for the single-digit-year speaker stamp.

**Potential WEAKNESS to flag (not a hard contradiction):**
- §tc-9 frames the speaker/transformer code as giving a usable build year once you cross-reference the era. The DB's **VG-0048 / VG-0100** stress that an EIA source-date code establishes only the **earliest possible** build date (the component could have sat in inventory before assembly). The page doesn't carry this "no earlier than" caveat for amps. **Recommendation:** add a one-line caveat (mirrors the honesty guardrail used on the guitar guides) — "a component code tells you the amp is no *older* than that date, not its exact build date." Low severity; improves accuracy + AEO trust.
- §tc-10: "sell your amplifier made before 1967" vs §tc-1's scope note "vintage Fender amps made in 1980 & before" vs the table running to T=1970 and Silverface era to 1980. The "before 1967" cutoff in the sell CTA is a **buying-preference statement** (what Joe wants to buy), not a dating fact, so it doesn't contradict the dating ranges — but a reader could read it as a dating boundary. Minor copy clarity only; no DB conflict.

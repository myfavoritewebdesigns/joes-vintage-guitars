### 3. FAQ gaps

The page has NO FAQ section and NO FAQPage JSON-LD, unlike several sibling model/serial pages that carry FAQ accordions. A 4-6 question FAQ at the bottom would (a) add FAQPage schema for AEO, (b) capture long-tail "ES-175" value/dating questions (this page is at pos 15.1 — schema could help the climb), (c) match the site's reference-page pattern. Suggested Q/A drawn from the page's own content:

- **Q: How can I tell if my Gibson ES-175 has PAF humbuckers?** A: P-90 single-coils ran 1949 to 1956; the "Patent Applied For" (PAF) humbucker arrived in 1957. A 1957 to 1959 ES-175 with original PAFs is the peak of the vintage market — check for the "Patent Applied For" decal on the underside of the pickup. *(page body; VG-0003 PAF = Patent Applied For / Seth Lover; VG-0026 PAF decal era for the decal-location detail.)*
- **Q: Is a Natural (Blonde) ES-175 worth more than a Sunburst?** A: Yes, significantly. Blonde finishes used Gibson's highest-grade maple and were made in much smaller numbers, so a late-1950s blonde is a "blue-chip" guitar that can reach roughly double a Sunburst of the same year. *(page body; VG-0112 originality/finish as dominant value drivers.)*
- **Q: What is "The 1965 Shift" on a Gibson ES-175?** A: Mid-way through 1965 Gibson narrowed the nut width from 1-11/16" to 1-9/16". Collectors usually pay a premium for the earlier, wider nut. 1965 also brought the nickel-to-chrome hardware change. *(page body; VG-0006 — note the ~1965 transition; see DB fact check on the nut-width spec.)*
- **Q: How much does a headstock repair or refinish lower an ES-175's value?** A: A clean, professionally repaired headstock crack typically cuts collector value by about 40% to 50% even when stable. A refinish also drops vintage value sharply — we use blacklight to check for the original nitrocellulose lacquer glow. *(page body; VG-0074/VG-0107 refin ~−40-50%; VG-0017 nitro fluoresces greenish under UV; VG-0018 blacklight blind spots.)*
- **Q: How do I date an ES-175 if the serial number is faded?** A: Check the potentiometer codes through the f-holes with a mirror — a 7-digit code starting with "137" (CTS) whose last four digits give the year and week the electronics were made. *(page body; VG-0047 137 = CTS; VG-0102 digits after the maker code = year then week; VG-0048/VG-0054/VG-0100 — MUST caveat: a pot code is a "no earlier than" floor, not a guaranteed build date. See DB fact check.)*

Mark VG-#### answers as needing DB sourcing per the citations above; the pot-code answer in particular must carry the VG-0048/VG-0054 caveat.

### 8. DB fact check

Cross-checked the page's factual claims against VG-0001..VG-0112.

**FLAGS / things to correct or caveat:**

- 🔴 **Pot-code dating stated as a "smoking gun" with no "no earlier than" caveat.** The page says the pot code's "last four digits tell you the year and week those electronics were made" and calls it "the 'smoking gun' for dating a Gibson." VG-0048 / VG-0054 / VG-0100 establish that an EIA source-date code gives only the EARLIEST possible build date (the date the *pot* was made, which can predate the guitar), and VG-0002 notes parts get swapped. Calling it a smoking gun overstates it. **Recommend adding the caveat:** "the pot code dates the electronics, which gives a 'no earlier than' floor for the guitar — a pot can predate the build, so corroborate with other features." (Not a flat contradiction, but a documented caveat the copy omits — matters for honesty/AEO. Note the code prefix: the page says "137," which is correct for CTS per VG-0047/VG-0101.)

- 🟡 **Nut-width "1965 shift: 1-11/16" to 1-9/16"."** The DB does not currently carry an ES-175-specific nut-width-change fact, so this is unverified against VG, though VG-0006 confirms ~1965 was a Gibson transition year broadly. The 1-11/16" → 1-9/16" mid-1965 narrowing is a widely-cited real Gibson change, but it's NOT in the verified DB — flag for verification before treating as DB-backed (and a good ADD candidate, below).

- 🟢 **PAF = "Patent Applied For" humbucker, introduced 1957** — CONFIRMED consistent with VG-0003 (PAF = Patent Applied For, Seth Lover) and the broad Gibson PAF-era timeline (VG-0025/VG-0041 place PAF adoption from 1957). ✓ (Page says "1957 changed everything," PAFs on 175 from 1957 — consistent.)
- 🟢 **Volute / "Norlin bump" on the back of the headstock near the nut, 70s** — CONFIRMED by VG-0005 (volute = carved triangular thickening at the neck/headstock), VG-0008/VG-0010 (volute added ~1969-1970), VG-0023 (Norlin era 1969-1986). ✓
- 🟢 **Refinish / headstock-repair value penalty ~40-50%** — CONFIRMED consistent with VG-0074 / VG-0107 (refin ~−40% average; headstock-crack repair penalty in the same band). ✓
- 🟢 **Blacklight checks for original nitrocellulose lacquer glow** — CONFIRMED by VG-0017 (aged nitro fluoresces greenish/yellowish under UV); should ideally pair with VG-0018 (UV blind spots) in the FAQ answer. ✓
- 🟢 **Orange paper label on the inside (visible through f-hole), faded/unreliable serials** — CONSISTENT with VG-0038 (Gibson hollowbody paper label ~1947-early-1961) and the 1961-69 serial-unreliability facts (VG-0011/VG-0013). ✓
- 🟢 **Originality is the dominant value driver; "player mods" (tuner footprints, swapped bridges) detract; modified/routed pickups = major hit** — CONFIRMED by VG-0112 (originality dominant) and VG-0106 (all-original definition); tuner-footprint logic consistent with VG-0002 (tuners commonly swapped). ✓
- 🟢 **Patent-Number pickups (1962-1965) sound nearly identical to PAFs, high-value middle ground** — CONSISTENT with VG-0024 (patent-number humbuckers ~1962-1965) and VG-0027 (no single DC value; hand-wound, near-identical). ✓
- 🟢 **Reverb/auction "realized prices over asking prices"** — CONSISTENT with VG-0108 (Reverb price guide = completed sales) and VG-0112. ✓

No claim on the page directly CONTRADICTS a VG fact. The only real correction is the pot-code "smoking gun" overstatement (🔴); the nut-width spec is unverified-but-plausible (🟡).

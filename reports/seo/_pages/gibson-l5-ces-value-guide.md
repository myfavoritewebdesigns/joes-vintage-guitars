### 3. FAQ gaps

The page HAS a strong 7-Q FAQPage already. Gaps where a Q/A would add coverage (and capture long-tail "value" queries the article deliberately withholds a number on):

- **Value section has no FAQ-friendly "what's it worth" Q.** Add: **Q: How much is a vintage Gibson L-5 CES worth?** A: Values swing widely on era, pickups, finish, and originality — a 1957-1960 PAF Venetian or a PAF-era Florentine can reach the highest tier, while later Norlin-era and modern examples sit lower. Because originality is the single biggest driver (VG-0112) and a refinish alone cuts value by ~50% (VG-0107), an honest figure needs a physical or photo inspection; that's what the free appraisal is for. *(Answer leans on VG-0107, VG-0112 — keep range-based, no fabricated dollar figures, consistent with the article's stated policy.)*
- **Dating section lacks a "how do I find the serial" Q.** Add: **Q: Where is the serial number on a Gibson L-5 CES?** A: 1950s and early-60s models carry an Orange Label visible through the bass-side f-hole with an A-prefixed (1950s) or 4-6 digit (1961-69) number; 1970-present models use an impressed 8-digit headstock serial. Note that 1961-1969 numbers are unreliable on their own (**VG-0011 / VG-0031 / VG-0036** — duplicated/overlapping) so confirm with features like the cutaway. *(Pairs with embedding video oxvMHi23bZc, §4 below.)*
- **Cases section has no FAQ.** Optional Q: **Q: Does an original case add value to a vintage L-5?** A: Yes — the Lifton "brown" 1950s case and the 1960s orange-lined black case are themselves collectible and an all-original guitar-plus-OHSC (**VG-0098**) commands a premium. ### 8. DB fact check

Cross-checked the page's factual claims against VG-0001..VG-0112. **No contradictions found** — the page is largely consistent with the verified facts. Specifics:

**Consistent / corroborated:**
- "PAF … introduced 1957 … after 1961, 'Patent Number' humbuckers" — matches **VG-0003** (PAF = Seth Lover's Patent Applied For) and **VG-0024** (patent-number pickups ~1962-1965, patent # is not the humbucker's). ✅
- "1950s … Orange Label … A-prefixed serial" — matches **VG-0038** (Gibson hollowbody paper label ~1947-early 1961) and **VG-0037** (1961 new system). ✅
- "1961-1969 … serial number duplicates from different years … features essential for dating" — strongly matches **VG-0011 / VG-0013 / VG-0031 / VG-0036** (1961-69 unreliable, overlapping; features required). ✅ Good to cite VG-0036 if adding the dating FAQ.
- "1970-Present … 8-digit system (YYDDDYPPP) … first two digits signify the year" — aligns with **VG-0035** (1977+ 8-digit YDDDYRRR, digits 1+5 give year). ⚠️ **Minor imprecision, not wrong:** the page's "YYDDDYPPP" mask and "first two digits = year" oversimplify the real YDDDYRRR scheme where the **1st and 5th** digits combine for the year (VG-0035, VG-0016), and the modern system began **1977**, not "1970." Recommend tightening the copy to "1977-present, 8-digit YDDDYRRR where digits 1 and 5 give the year" to match the verified fact. Flag as a **copy-precision fix**, low severity.
- "refinished vintage guitar usually loses 50% or more" — consistent with **VG-0107 / VG-0074** (refin ~-40% avg, can be more) and **VG-0017** (UV: aged nitro glows green) backs the black-light test claim. ✅
- "originality … is everything" / value thesis — matches **VG-0112** (originality is the single largest value driver). ✅
- Black-light "green glow" test — matches **VG-0017**; the page could optionally add VG-0018's caveat (UV blind spots: poly finishes / some modern lacquers don't fluoresce) for accuracy. Minor enhancement, not a flag.

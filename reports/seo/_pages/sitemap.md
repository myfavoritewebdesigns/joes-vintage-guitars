## sitemap

**Page type:** Archetype-B-ish utility page (`/sitemap/`). It is a pure HTML link directory: a title bar plus 6 groups (Main Pages, Sell Your Guitar, Serial Number Guides, Value Guides, Services, Policies) rendering 32 `<a>` links. There is **no prose copy** on the page — every link is a bare nav label.

**Linkgraph context that shapes this whole analysis:**
- `/sitemap/` is itself an **orphan** (zero in-content inbound links — it's reachable only via footer/nav). It also already emits **32 out-links** (one per listed page), so it is NOT under-linked outbound.
- Critically, the linkgraph shows the sitemap is the *only* in-content inbound link several priority pages have: it is 1 of just 2 inbound for `/vintage-fender-amplifier-serial-numbers-how-to-find-the-year/`, 1 of 3 for `/rickenbacker-serial-numbers/`, **the sole inbound** for `/sell-your-vintage-dangelico-guitar-in-the-us/`, and a listed inbound for every `/sell-my-*/` page. So the sitemap is load-bearing link equity for the long tail. The recommendations below are about **anchor-text quality and a couple of missing/over-thin entries**, not adding net-new contextual links into prose (there is no prose).

Because the page is a link list, the standard subsections map differently than on a content page. I've kept all 8 and flagged the ones that are structurally N/A.

### 2. Section-level related posts

**N/A as designed.** A sitemap is a navigation directory; an inline "Related reading" block does not belong inside a link list. The *correct* expression of "related posts on this page" is recommendation #1 above — add a curated **"Guides & Articles" group** that surfaces the flagship evergreen posts. That is the sitemap-appropriate form of "related reading": a permanent, curated set of the best guides, not a per-section inline block.

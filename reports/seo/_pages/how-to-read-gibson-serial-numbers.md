### 3. FAQ gaps

The page has a strong 12-Q FAQ at the bottom but several long *sections* have no localized Q/A. Suggested additions (mark DB-needed answers):

- **Modern System (1977–Present) section** — no FAQ. Add:
  - Q: "How do I read an 8-digit Gibson serial number?" A: first + fifth digits = last two digits of the year; digits 2–4 = day of the year (YDDDYRRR). **VG-0035** (and VG-0016 for the plant-rank detail).
  - Q: "Why does my Gibson serial start with 94 but isn't from 1994's normal sequence?" A: the 1994 Centennial exception (already in body copy; promote to FAQ).
- **Reused Number Era section** — no FAQ. Add:
  - Q: "Why does my 1960s Gibson serial number match more than one year?" A: 1961–1969 numbers were duplicated/reused; serial alone can't date them — confirm by physical features + pot codes. **VG-0011 / VG-0013 / VG-0031 / VG-0032 / VG-0036** (cite 100000–106099 = 1963 or 1967).
  - Q: "Can a pot code date a 1960s Gibson?" A: it gives only the earliest-possible build date (no-earlier-than). **VG-0099 / VG-0100 / VG-0102**.
- **Custom Shop / Historic Reissue section** — no FAQ. The two existing top-of-page FAQ-schema Qs (Custom Shop CS prefix, Les Paul Classic) are in JSON-LD but NOT rendered as visible accordions — recommend surfacing them as visible Q/A here so schema and on-page match (avoids "FAQ markup not visible on page" Rich-Results risk).
- **FON section** — well covered in-body but no FAQ. Optional Q: "What's the difference between a Gibson FON and a serial number?" A: FON = internal batch number ink-stamped on bare wood, used ~1902–1961, often assigned before completion (so a 1959 ES-335 can carry a 1958 FON). **VG-0012 / VG-0039**.

**Facts on this page MISSING from the DB — recommend adding (with the page as source, Joe-authored):**

- **VG-NEW (Gibson FON suffix/prefix split):** Gibson FONs used a **trailing** letter for year 1935–1942 (A–H) but a **leading** prefix letter for year 1952–1961 (Z=1952 … Q=1961). The DB has the 1935–42 suffix (VG-0034) but NOT the 1952–61 *prefix* (Z–Q) mapping. Add it. Source: page FON prefix table.
- **VG-NEW (FON-vs-serial year gap):** a Gibson FON is assigned when a batch *enters* production, so a guitar can carry a FON one year earlier than its serial — e.g. a 1959 ES-335 with a 1958 FON. Extends VG-0012/0039. Source: page "Real World Example" callout.
- **VG-NEW (1994 Centennial exception):** for most of 1994 Gibson abandoned the split-digit system and began every serial with "94"; confirm via 100th-anniversary 12th-fret banner inlay / headstock coin. Not in DB. Source: page modern-system warn callout.
- **VG-NEW (2010s year-stamp exception):** in a brief 2010s window Gibson stamped the literal 4-digit year of manufacture below "MADE IN USA," overriding the split-digit decode. Not in DB. Source: page modern-system callout.
- **VG-NEW (Les Paul Classic serial format):** Classic used an ink-stamp serial 1989–2014 — 1 year-digit (1989–99) vs 2 year-digits (2000–14), no "Made in USA" on the core model; only the 2007 Classic *offshoots* (Antique/Custom/GotW) used the modern 9-digit impressed serial + MIUSA stamp. Not in DB; useful authentication fact. Source: page Les Paul Classic section.
- **VG-NEW (Historic Reissue R-number serial):** Historic Reissue Les Pauls (R4/R7/R8/R9/R0) ink-stamp serial = first digit is the *reissued vintage year* (9 = 1959 reissue), second digit = last digit of *actual* build year, rest = rank. Not in DB. Source: page Custom Shop/Reissue section.
- **VG-NEW (ES-330 vs ES-335 tells):** ES-330 = fully hollow (no center block), P-90s, 16th-fret neck joint pre-1968; the 1968+ ES-330L "long neck" moved the joint to the 19th fret like the 335. Useful model-ID fact, not in DB. Source: page ES-330 section.
- **VG-NEW (ES-335 cutaway dating):** rounded "Mickey Mouse ear" horns = 1958–1961, pointed horns = 1962+. Complements VG-0045 (dot→block). Source: page ES-335 cutaway section.

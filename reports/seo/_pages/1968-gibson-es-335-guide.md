### 3. FAQ gaps

The page has a strong 6-question FAQ already (all-original check, 1968-vs-1969, worth, serial decode, best way to sell, vs 1959/1962). Genuine gaps where a Q/A would add value and capture long-tail queries:

- **Hardware/Electronics section lacks an inline FAQ.** Suggested:
  - *Q: Are 1968 Gibson ES-335 T-top pickups as good as PAFs?* A: T-tops trade the PAF "mystique" for a consistent, articulate output many jazz and blues players prefer; they carry a "Patent No" sticker (not a hand-stamped PAF label) and sit well below PAF prices, which is part of the 1968's value case. (No DB fact needed — VG-0003 confirms PAF definition if you want to reference it.)
  - *Q: How do I read the pot codes on a 1968 ES-335?* A: Format 137-68XX — 137 = CTS, 68 = 1968, XX = week. Four matching pots = strong confirmation; the code gives the EARLIEST possible build date, so cross-check the headstock. **Needs DB fact: VG-0099 / VG-0101 / VG-0102 (EIA maker code 137 = CTS, year-then-week, "no earlier than" caveat).**
- **Color Palette section** could carry:
  - *Q: What is the rarest 1968 Gibson ES-335 finish?* A: Pelham Blue, Polaris White, and Ebony are ultra-rare special-order finishes; a true period Pelham Blue often reads closer to teal/seafoam today because the lacquer yellows. (Page-sourced; no DB fact required.)
- **Case section** could carry:
  - *Q: Does the original case affect a 1968 ES-335's value?* A: Yes — a matching Lifton or Victoria case with the original Marigold/orange plush lining signals an undisturbed instrument and commands a premium. (Page-sourced.)

Mark for review: any pot-code answer that states the dating logic should cite VG-0101/VG-0102 to stay honest about the "earliest possible build date, not exact date" caveat.

| §"How to Date Your Gibson LG: FONs" | "What is a Factory Order Number (FON) on a Gibson?" | A FON is a production-**batch** number ink-stamped into the wood (neck block), not a serial number; on 1940s–50s LGs it is often the only number present and the better dating clue. **VG-0012 / VG-0039** — verify wording against the approved DB phrasing. |
| §"Internal Architecture" / "Inside Secret" (back strap) | "Does the interior back strip tell me which LG model I have?" | A vertical spruce reinforcement strip over the back center seam indicates an X-braced LG-2/LG-3 (professional tier); a smooth mahogany back with no strip indicates the LG-0/LG-1 economy build. ### 8. DB fact check

Cross-checked the page's factual claims against VG-0001…VG-0112 (full text in `local-databases/vintage-guitar-db/guitar-facts/VG_FACTS.md`).

**Claims that CHECK OUT (consistent with DB):**
- FON is a batch number ink-stamped inside the body (neck block), distinct from the serial number, used into ~1961, and often the better dating clue on older guitars → consistent with **VG-0012, VG-0039**.
- Banner-era FON format "four-digit number followed by a letter (like 7412 H)" with the trailing letter encoding the year → consistent with **VG-0034** (A=1935 … H=1942, letter at the END of the FON; H=1942 fits the wartime Banner window).
- "Gibson reused these numbers throughout the 1960s... physical specs just as important as the number" → consistent with **VG-0011/0013/0031/0036** (1961–69 serials unreliable) and **VG-0014** (never date on serial alone; confirm with features).

**⚠️ FLAG — needs verification (possible imprecision, not clearly wrong):**
- **Page claim:** *"Letter Prefixes (1952 to 1961): Gibson used a letter at the START of the code to denote the year. For example, a code starting with 'V' is from 1956, while 'U' is from 1957."* The DB's only FON-letter rule, **VG-0034**, is the **1935–1942 suffix** system (letter at the END). The page asserts a **second, later (1952–1961) prefix** system that the DB does **not** cover. This is plausibly correct (standard references do document a 1950s Gibson FON letter-prefix where the letter denotes the year), but the **specific V=1956 / U=1957 mapping is NOT in the DB and is unverified here.** Treat as a candidate to verify before relying on it, and note the page conflates "suffix letter (1935–42)" with "prefix letter (1950s)" without distinguishing them — readers could misapply the wrong rule. Recommend: verify the 1950s prefix→year table against a primary reference and, if confirmed, add it to the DB (see below).

**No outright contradictions found.** The bracing/finish/nut-width/bridge claims are LG-model-specific build details outside the current DB's coverage (DB is Les Paul / ES / Burst / Fender / Martin heavy) and were not contradicted.

**Solid facts on this page MISSING from the DB — recommend adding (with visible source = this page's expert claims; verify before insert):**
1. **Gibson FON letter-PREFIX year code, ~1952–1961** (e.g. V=1956, U=1957) — fills the gap between VG-0034 (1935–42 suffix) and VG-0039 (general FON). High value for the Gibson serial cluster. **Verify the full prefix→year mapping first.**

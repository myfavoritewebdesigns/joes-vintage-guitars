# J-200 Design Comparison

The new guides reuse the existing J-200-style guide kit. The unchanged J-200 page is the left-hand reference at both acceptance widths. Value pages use the chart; authentication pages use a checklist and Photo Timeline archive. Separate full first-screen screenshots for every guide are in this folder.
